let transaction надо чтобы переменная transaction была доступна в catch, а создание транзакции выполнялось внутри try.
Если написать const transaction внутри try, в catch её не будет видно. Если создать перед try, ошибка создания транзакции не попадёт в этот catch.
let нужен только для такой структуры обработки ошибок.
